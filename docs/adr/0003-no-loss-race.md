# No-loss race: stars for balloons, not placement

**Status:** accepted · 2026-10-31

A racing game normally ends in a placing, and a 5-year-old can lose repeatedly without understanding why. We chose a race that always completes: the car auto-accelerates, soft guardrails and auto-recovery prevent dead ends, rivals are rubber-banded and never block, and the only rating is one to three stars earned by finishing and collecting balloons. Placement is decorative. This keeps the emotional stakes on exploration and mastery — “I found all the balloons” — rather than on beating someone, and it lets siblings of different ages play the same track without a loser. The trade-off is that competitive 8–10-year-olds will find it gentle; speed and AI values are kept in one tuning file so an optional Fast mode can be added later without changing the product model.
