# Portrait-only game design

**Status:** accepted · 2026-10-31

The primary device is a phone held vertically by a 5–7-year-old, often with one hand or resting on a table, and the game must work in that posture. We chose a portrait-only product: a 9:16 canvas, a tall chase camera with corner look-ahead, a vertical track ribbon, and thumb controls at the bottom. A landscape racing layout would show more road, but it assumes two-handed grip and a deliberate rotation that young children rarely perform; portrait also matches how the phone is already held when a parent hands it over. Installed PWAs declare portrait, and a friendly rotate overlay covers the game when a coarse-pointer device is held sideways. The cost is a narrow horizontal field of view, which is why the camera leads into corners and the HUD uses vertical space rather than a mini-map.
