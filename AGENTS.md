# Zoom Town project rules

## Non-negotiables

- **Portrait only.** The game is designed for a phone held vertically; do not add a landscape layout.
- **No browser speech synthesis.** Never call `speechSynthesis` or `SpeechSynthesisUtterance`. Every voice line is a committed local audio file generated by the local studio.
- **No external audio or art at runtime.** Do not load audio, models, fonts, or textures from a CDN. The game must work offline after the first load.
- **iOS install guidance is part of the product.** iOS Safari has no `beforeinstallprompt`; keep the first-visit banner, the Safari share-sheet instructions, the Settings → Install app entry, the 152/167/180 touch icons, `apple-mobile-web-app-capable`, and the standalone/portrait/offline behaviour working.
- **No ads, links, accounts, analytics, or runtime network requests.**
- **A 5-year-old must be able to play unaided.** Clarity and forgiveness beat visual polish, frame rate, and extra content.
- **No emoji** in UI, art, or assets. Use original SVG/CSS shapes and plain symbols.
- **Ages 5–7 only.** Speed and AI values live in one tuning file so a Fast mode can be added later, but do not add one now.

## Audio

- Source: `../music-sfx-voice-studio` on `127.0.0.1:7910` (Qwen3-TTS, Stable Audio 3, procedural SFX).
- Regenerate: `pnpm audio --voices`, `pnpm audio --sfx`, `pnpm audio --music`, or `pnpm audio --all --force`.
- Output: `static/audio/`; the generated list is recorded in `.audio-raw/manifest.json` (provenance only, never fetched at runtime).
- Italian and English voice files must stay in parity.

## Checks before claiming done

```sh
pnpm check
pnpm lint
pnpm test:unit
pnpm test:e2e
pnpm build
```

`pnpm test:e2e` builds first and runs Playwright against the production build with
`?debug=1`; the debug hook does not exist in a normal page load.

## Code rules

- **All UI copy lives in `src/lib/i18n.ts`**, Italian and English in parity. No new
  inline `lang === 'it' ? … : …` in components, and every accessible name comes
  from the same table.
- **Anything removed from the scene is disposed.** Use `disposeObject3D` from
  `src/lib/game/dispose.ts` when dropping cars, rivals, balloons or a track.
  Shared resources (wheel mesh, balloon trim) are marked once with
  `markSharedResource`; never dispose a shared geometry.
- **Overlays use `use:modal`** (`src/lib/components/modal.ts`) so focus is
  trapped, Escape closes, and the game behind is `inert`.
- **`window.__zoomtown` is test-only** and is installed only when the URL has
  `?debug=1`.
